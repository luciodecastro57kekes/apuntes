Git

Git es un sistema de control de versiones distribuido. Su función principal es registrar todos los cambios realizados en el código de un proyecto a lo largo del tiempo, permitiendo volver a estados anteriores (como una máquina del tiempo) y facilitando el trabajo colaborativo sin perder información

Sirve para:

  • Controlar versiones: Guarda "fotografías instantáneas" de tu trabajo. Si cometes un error, puedes restaurar el proyecto a una versión anterior rápidamente
  • Trabajar en equipo: Múltiples personas pueden modificar los mismos archivos al mismo tiempo sin sobrescribir el trabajo de los demás.
  • Experimentar de forma segura: Permite crear "ramas" (versiones paralelas) para probar nuevas funciones sin alterar la versión principal.

GitHub

¿Para qué sirve?

GitHub es una plataforma en la nube que funciona como un "Google Drive" para programadores. Aloja proyectos de software y utiliza el sistema de control de versiones Git, permitiendo a los desarrolladores guardar su código, colaborar de forma remota y llevar un registro de cada cambio realizado.

  • Control de versiones: Permite guardar el historial de un proyecto y volver a cualquier versión anterior si algo sale mal (como una máquina del tiempo).
  • Trabajo en equipo: Facilita que múltiples personas modifiquen el mismo código al mismo tiempo sin sobrescribir el trabajo de los demás.
  • Respaldo seguro: Mantiene copias de seguridad de todo el código en la nube.
  • Portafolio profesional: Funciona como una red social para desarrolladores. Los programadores comparten su trabajo público y las empresas lo revisan como parte de sus procesos de contratación.
  • Proyectos de código abierto: Millones de proyectos públicos permiten a cualquier usuario descargar aplicaciones o contribuir con mejoras.
